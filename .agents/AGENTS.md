# Project Rules for Pali Tycoon (บาลีส่วนฐี)

## Git & Deployment Instructions
- **Auto-Push to GitHub**: Whenever you complete a feature, bug fix, or modification requested by the user, ALWAYS test the build with `npm run build`, stage all changes with `git add .`, create a clear commit with `git commit -m "..."`, and push directly to GitHub (`git push origin main`) proactively without waiting for the user to ask.
